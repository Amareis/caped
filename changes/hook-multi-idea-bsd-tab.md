## Why

Хук commit-msg имеет правило «one idea per commit» (973ce89, 2026-08-24 15:05) —
коммит, трогающий ≥2 файла идей, должен отклоняться. На macOS правило не работает:
счётчик теряет файлы. Найдено в kudach при пакетной конверсии openspec-идей —
пять мульти-идейных коммитов (2+2+3+3+4 идеи) прошли без единого писка, при том что
per-file сверка `Idea:` трейлеров работает честно.

## Context

`scripts/hooks/commit-msg`, счётчик:

```sh
IDEA_TOUCHES="$(printf '%s\n' "$NS_ALL" | grep -E '^(A|M)\tideas/[^\t]+\.md$' | ...)"
IDEA_COUNT=...
if [ "$IDEA_COUNT" -gt 1 ] && [ -z "$RENAMES" ]; then err "..."; fi
```

BSD grep (macOS): `\t` ВНЕ bracket-выражения матчит реальный таб (поэтому паттерн
вообще что-то находит), а `\t` ВНУТРИ `[^\t]` — это класс «не бэкслеш и не буква t».
Итог: из счётчика выпадает любой файл идеи с буквой `t` в имени.

Эмпирика (kudach, 2026-08-24):

- `A\tideas/foo.md` — считается; `A\tideas/_t1.md` — НЕ считается (rc=1 на grep).
- Пачка b55bdd5 (venue-organizer-vibe + event-time-of-day-inference): второй файл
  невидим (`t` в «time») → COUNT=1 → пропуск.
- Пачка c286945 (agent-context-decisions-digest, agent-wake-on-return,
  better-moderation-context): все три с `t` → COUNT=0 → пропуск.
- Пачка f39a084 (четыре идеи, все с `t`) → COUNT=0 → пропуск.
- Per-file чеки (`edit of idea … trailer required`) не затронуты — они парсят поля
  через `IFS=$'\t'` и работают (ловили правку agent-moderator-split без трейлера).

Тот же `\t`-в-скобках паттерн сидит в RENAMES (`^R[0-9]*\tideas/[^\t]*\.md\tideas/...`)
— там второй `\t` тоже вне скобок и ОК, но стоит проверить заодно.

Фикс тривиальный: реальный таб внутри скобок — `$'...[^\t]...'` → вставить буквальный
TAB-символ: `[^<TAB>]`, или перейти на IFS-сплит как в per-file чеках.

## Requirements

- Мульти-идейный гард на macOS считает все затронутые файлы идей, включая имена с
  буквой `t`: коммит с ≥2 A/M `ideas/*.md` отклоняется с честным «split» сообщением.
