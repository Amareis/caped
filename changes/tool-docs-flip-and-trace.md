## Why

Первый боевой флип капы в enforced (kudach, web-version) показал: процесс
пришлось реверс-инжинирить по скриптам вместо чтения правил тула. Четыре
конкретных провала документации и одно пожелание.

## Context

Живой флип 2026-08-24 (kudach, web-version-cap-flip): подготовительные коммиты
неожиданно попали под enforced-режим, трассировка падала в RED на ложных ref'ах,
а синтаксис атрибутов маркера пришлось читать из regex'а. Хук читает реестр из
РАБОЧЕГО ДЕРЕВА: правка `caped.registry` включает enforced-режим мгновенно, ещё
до коммита.

## Requirements

- Флип документируется в дампе и README: реестр читается из рабочего дерева
  (контракт-требования enforce мгновенно, до коммита); процедура: 1) подготовка
  сколько угодно коммитов, пока капа НЕ enforced, 2) ОДИН contract-коммит флипа
  (README капы + маркеры + реестр + чистка рефереров, `Behavior: contract` +
  `Spec:`), 3) реестр раньше времени не трогать.
- Trace-зона предупреждена: ref = `[#word]` в ЛЮБОМ tracked-файле (кроме
  спек/идей/чейнджей) — включая комментарии и строки прозы/URL; паттерн вне
  маркерного контекста — это ref (ложные срабатывания: URL `[#payload]`,
  комментарий `[#neighbor-relay]`). Предупреждение, не сужение зоны:
  комментарии — законная поверхность refs ({#trace-refs}).
- Синтаксис атрибутов маркера `- [#slug no-test dump]` (атрибуты внутри скобок)
  — в rules-дампе, а не только в README.
- Одна строка границы: `caped check` = контент/фронт-маттер, `caped trace` =
  покрытие требований тестами.
- Парк (пожелание, НЕ этот чейндж): эталонный README enforced-капы и/или
  генератор `caped init-cap <name>` — скелет с `## Requirements` и парой
  буллетов-примеров — депозит в бэклог при архиве.

## Decisions

- Зона refs НЕ сужается: тест-комментарии — легитимные refs ({#trace-refs});
  ложь из прозы/URL закрывается предупреждением, а не потерей легальных
  поверхностей.
- Флип — документ, не код: механика уже позволяет один контрактный коммит,
  фиксируем процедуру.
- `init-cap`-генератор — отдельная фича, паркуется (депозит при архиве).

## Rejected alternatives

- Сузить трассировку (только кодовые сценарии): ломает комментарий-рефы и
  часть тестов; цена выше ложных срабатываний. Отклонено в пользу
  предупреждения.
- Делать флип реестра всегда отдельными коммитами (реестр в своём):
  подготовка «маркеры без контракта» бессмысленна; один флип-коммит — ровно
  описывает происходящее. Отклонено.
