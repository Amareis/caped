## Why

Доставка идеи соседу сегодня — три коммита: домашний `Idea:` → релей → `Archives:`
withdraw. Для «послать записку соседу» это избыточно: домашний коммит нужен только
затем, чтобы релей его тут же отозвал. Плюс атрибуция: соседний коммит штампуется
`Agent: ${CAPED_AGENT:-human}` — у агента-отправителя env не выставлен, идея
live-roster-inject уехала как `human` (депозит в _backlog 2026-08-24).

## Context

- Живой кейс (2026-08-24): kudach → caped-context, идея была нужна только там;
  домашняя пара коммитов — чистый шум истории.
- Релей после фикса ставит `Behavior: internal` на соседний коммит (d39c757) —
  транспорт работает, шероховатости в UX-контракте.
- Идентичность отправителя известна: плагин инжектит «you are <id>»; резидентный
  presence-файл есть в домашней репе.

## Requirements

- `caped relay <nb> <idea>` принимает НЕЗАКОММИЧЕННЫЙ файл идеи: доставка соседу
  без домашних коммитов вообще (файл после отправки удаляется или остаётся по
  флагу); закоммиченная идея релеится как сейчас.
- Id отправителя — обязательный, БЕЗ дефолта `human` вообще (дополнение человека
  2026-08-24: «дефолт human не делай — я сам укажу human, пусть параметр
  обязательный будет всегда просто»): параметр (CAPED_AGENT/аргумент) требуется
  всегда; ручной запуск — `CAPED_AGENT=human` явно. Соседний коммит несёт
  `Agent: <id>@<home>`.
- Withdrawal-коммит делается только когда было что отзывать (идея была в гите).

## Decisions

- Ид отправителя — обязательный аргумент, не env-default: атрибуция — контракт, а
  не оптимизация (депозит 4cb3a6e — provenанс утекал при `-:-human`).
- Прямой режим = локальный файл untracked (соседу идёт только его коммит, дома —
  ноль коммитов); нормальный режим = tracked (копия + соседний коммит + локальный
  withdraw/--keep) — граница по `git ls-files`.
