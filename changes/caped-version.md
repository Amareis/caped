## Why

Подъём из `_backlog` (запись №5, 2026-08-23): tool-changelog сделал бандл и событие `tool-updated`, но публичной команды-контракта для консьюмера нет — «получается недоделано». Плагин не должен знать путь к бандлу сам; точку даёт тул: `caped version` печатает версию-строку (первая строка бандла), `--path` — путь к содержимому.

## Context

Бандл: `scripts/CHANGELOG.caped.generated.md` рядом со скриптами тула (linked-mode; override `CAPED_BUNDLE_PATH` для тестов) — регенерится автоген-хуками по `contract`/`archived`. Событие `tool-updated` уже пишется в ленту при смене версии-строки. reminder-timing (caped-context) ждёт команду: на событии дёрнуть `caped version` и вплести строку в контекст. `render changelog` рендерит контракты ТЕКУЩЕГО репо — это НЕ бандл тула; команда закрывает различение.

## Requirements

- `caped version`: печатает первую строку бандла (версия-константа «caped changelog: N contract change(s) · head …») — без знания пути консьюмером.
- `caped version --path`: печатает путь к бандлу (чтение содержимого — контрактов тула — по выданному пути).
- Без бандла — явный ответ (нас-колько «нет бандла — собрать тул/дождаться автогена»), exit 0, не инфраструктурная ошибка.
- Дамп COMMANDS + README `#tool-version` получают строку про команду.
- Тесты (events-сьют): версия-строка и --path по самодельному бандлу; без бандла — понятный ответ.
- just test зелёный.

## Rejected alternatives

- «Плагин находит бандл по пути сам» — отвергнуто: путь — внутренняя деталь тула, контрактная точка — команда; иначе каждый консьюмер ломается при переезде тула.

## Provenance

Человек (дословно): «Давай версию то сделаем? А то получается недоделано».

Додумано агентом (с основаниями):

- Команда, а не путь — основание: тот же принцип «консьюмер не парсит внутренности» (лента, livе-состояние); переезд тула не роняет консьюмеров.
- Отсутствие бандла = валидный ответ exit 0 — основание: в adopting-репо бандл может ещё не существовать (первый запуск); информация, а не ошибка.
