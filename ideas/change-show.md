## Why

Постулат модели — «актуальная история без лазанья в гит/тесты», но сегодня поднятие истории сущности — ручной трёхшаговый ритуал: `render history` (найти имя и хэши) → `git log --grep <name>` (коммиты по трейлеру) → `git show '<archives>^:changes/<name>.md'` (финальный текст). Человек прямо сказал, что вручную этого делать не будет — значит, без команды модель не работает. Живой кейс 2026-08-23: проверка «правильно ли веб-агент записал променанс из диалога» потребовала всех трёх шагов.

## Context

Все данные уже в гите и воспроизводимы (продемонстрировано вручную на complete-rules-dump): таймлайн — из трейлеров (`Idea:`/`Change:`/`Archives:`), финальный текст — из родителя Archives-коммита (тот же приём, что `archived_summary` в caped-render.py), живой текст — из файловой системы. Команда — сборка существующих кирпичей, не новая сущность. `depends_on: render-format` — общий JSON-слой и тот же файл `caped-render.py`; очередь, а не дубль форматировщика. Променанс-истина (дословность цитат) лежит вне гита — в сессиях харнесса; это территория session-export, change show на неё только ссылается.

## Requirements

1. `caped render change <name>` (или топ-левел `caped change show <name>` — O1): печатает текущий/финальный документ сущности, таймлайн событий с датами и хэшами (рождение, взятие в работу, ренеймы, архивация), список всех коммитов с трейлером `Change: <name>` (+ `Idea:`-коммит рождения), включая адхок-стиль тела.
2. Неизвестное имя — понятная ошибка с ближайшими кандидатами (fuzzy по именам из history + живых файлов), exit 2.
3. `--json` по схеме из render-format (та же сущность + массив событий/коммитов); text-дефолт читаем глазами.
4. Тесты: сценарии в `tests/render/test_render.sh` — живой чейндж (текст из FS), архивный (текст из `show <arch>^:`), неизвестное имя (exit 2 + кандидаты).

## Rejected alternatives

- **Материализованный архив** (копии файлов при архивации, чтобы show читал их) — отклонён глобально: архив — derived view, гит уже хранит.
- **Хранить ссылки на коммиты в самом файле чейнджа** — дубль того, что гит пишет сам; дрейф.

## Provenance

Человек (дословно):

- «как теперь поднять историю идеи? Например я хочу проверить, правильно ли дипсик мой променанс из диалога записал — как это сделать? Представим, что у тебя этот файл не в контексте»
- «show точно нужен для полноты истории — я вот вручную точно не буду в гит историю лазить»

Додумано агентом (с основаниями):

- Ручной ритуал работает, но не масштабируется на человека — основание: прямая цитата + собственная демонстрация 2026-08-23 (три команды для одной проверки).
- depends_on render-format, а не параллельно — основание: тот же `caped-render.py` и общая JSON-схема сущности; параллельные чейнджи на одном файле — лишние конфликты.
