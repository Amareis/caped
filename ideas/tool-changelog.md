## Why

Поднято из `_backlog` (запись 2026-08-23, фаза 2 caped-event-hooks): сессии и adopting-репы должны видеть «тул изменился» БЕЗ парсинга чужой истории. Версия тула = голова встроенного чейнджлога (derived из contract-коммитов — халявный чейнджлог уже есть в истории), событие `tool-updated` в ленту — сверка версии-константы с курсором сессии (`.caped/state/tool-version`).

## Context

Лента v0 архивирована (caped-event-hooks, 94ef8d2): feed.jsonl + post-commit эмиттер + дистрибуция `.caped/hooks`. Недостаёт: view `render changelog`, версия-константа, автоген (хук `.caped/hooks/contract`/`archived` в tool-репо регенерит бандл), событие `tool-updated` (эмиттер сверки на запуске), бинарь вшивает при сборке (caped-cli). В linked-mode файл-бандл лежит рядом со скриптами, заигноренный.

## Requirements

- View `render changelog`: derived из contract-коммитов + архивов + адхоков (Spec: подпись), text+json+`--write`; ГОЛОВА файла = версия-константа тула.
- Автоген: версионированный хук `.caped/hooks/contract` (+ archived) в tool-репо после события регенерит бандл (`scripts/CHANGELOG.caped.generated.md`, игноренный, в linked-бандле); ритуала регена руками нет — дрейф исключён по конструкции.
- `tool-updated`: эмиттер сверки версии-константы с `.caped/state/tool-version` на каждом запуске (чтения копейки); смена → строка в ленту.
- Бинарь: сборка вшивает сгенерированный чейнджлог (caped-cli).
- Тесты: render-сценарий changelog, хук-сценарий автогена (contract-коммит → файл регенерирован), событие tool-updated; just test зелёный.

## Rejected alternatives

- Версия = git-HEAD тула — отвергнут: шумит на не-поведенческих коммитах; голова чейнджлога точнее (см. caped-event-hooks).
- Ручной ритуал регена — отвергнут (запрошен был: «зачем ритуал, если ивенты будут»): автоген по событию.

## Provenance

Человек (дословно):

- «Ну так нам же никто не мешает сделать дамп чейнджлога при разработке и носить его с собой в бинарнике? Это ж просто еще один render view получается?»
- «Зачем ритуал регена если у нас там же прям ивенты будут? Ты ж можешь принудительно его регенить просто по ивенту архивации чейнджа или когда там надо?»
- «Хм, а где ивенты? Или следующая идея уже нагенерит?» — подъём из бэклога: первое живое событие = рождение этой идеи.

Додумано агентом (с основаниями):

- Версия-константа = голова бандла — основание: linked-mode встраивает один файл, сверка дешёвая, контент «что изменилось» читается локально из бандла без chужой истории.
- Автоген по событию (contract/archived хук) — основание: реген в пост-коммит участвует в потоке, дрейф невозможен по конструкции; событийная лента — готовый триггер.
