## Why

Инструмент без истории на Хабре тонет: «ещё один воркфлоу для LLM-агентов» уже вызывает аллергию.
У проекта есть редкие активы — живая история провала (спеки, болтающиеся сбоку от 50k строк Rust),
померенный догфудинг и честные границы. Запуск надо спроектировать, иначе статья превратится в
манифест, написанный по памяти за вечер.

## Context

Угол: не тул, а боль — «код агентами пишется быстрее, чем успеваешь забыть, зачем он нужен».
Рицепты, которые уже есть и надо только собрать: коммиты, завёрнутые хуком; trace, поймавший баг
до человека (резолв дампа против self-host фикстур); замер «5.7 КБ ратионале адхока живут ТОЛЬКО
в коммит-месседжах» (идея {#git-text-metrics}). Верхняя точка демки — инкрементальная адаптация:
всё можно вести руками через CLI, а можно открыть харнесс (dsh-плагин + мультиагентность), где
рендерятся статусы и агенты запускаются одной кнопкой — человек только принимает решения. Эта
картинка одновременно является целевой для {#caped-web} и продаёт подход лучше любых диаграмм.

## Requirements

- Статья публикуется после v0 (минимум kudach-adoption: «вот 50k строк Rust, вот вход за один
  `caped init`, вот первая enforced-капа») — без живого adopting-проекта это теория.
- Идеальный тайминг — после caped-cli: «установка = один бинарь» снимает рефлекторный комментарий
  «баш-скрипты, серьёзно?»; альтернативный нарратив «2к строк баша делают то, чего не смог
  отдельный трекер» допустим и до бинаря.
- Обязательная секция честных ограничений: capability-нарезанный код, субъективность границы
  адхока, флаки слабых моделей на ритуале — доверие важнее впечатления.
- Каскад: Хабр → перевод на dev.to → Show HN (с бинарём и гифкой: init → завёрнутый хуком коммит
  → render plan).

## Decisions

## Rejected alternatives

- Публиковаться сразу после v0 без бинаря — не отвергнуто окончательно: если kudach-adoption даст
  сильную демку раньше cli, нарратив «2к строк баша» самодостаточен; решение по факту готовности.

## Provenance

Человек (дословно):

- «Как сделаем v0/0.1 — как это можно рекламировать на хабре том же?»
- «А если там уже и плагин к dsh будет с хорошей мультиагентностью рабочей — получается у нас
  вообще инкрементальная адаптация будет, можно руками все вести через cli, а можно открыть
  харнесс, там сразу рендерится статусы и по одной кнопке сразу агенты запускаются, тебе только
  решения принимать надо... Бля, красиво звучит прям»
- «Да, давай — чотко получается»

Додумано агентом (с основаниями):

- Риск «аллергии на воркфлоу-статьи» и требование рицептов вместо манифеста — основание:
  профиль контента Хабра за 2025-2026 (волна MCP/агентных туториалов).
- Каскад каналов Habr → dev.to → Show HN — основание: тема provenance/spec-drift горячая в
  англоязычном сегменте, русскоязычная боль недопредставлена.
